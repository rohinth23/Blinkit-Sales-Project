# 🛒 Blinkit Sales Analytics Dashboard | Power BI

## 📌 Project Overview

The Blinkit Sales Analytics Dashboard is an interactive business intelligence project developed using Microsoft Power BI. The dashboard analyzes sales performance, product categories, outlet characteristics, customer ratings, and location-based sales trends.

The objective is to transform raw sales data into meaningful insights that help understand business performance and support data-driven decision-making.

 🎯 Project Objectives

- Analyze overall sales performance and revenue.
- Identify top-performing product categories.
- Compare sales across different outlet types and sizes.
- Understand customer preferences and ratings.
- Evaluate sales trends and business KPIs.

## 📊 Key Performance Indicators (KPIs)

- Total Sales: Overall revenue generated.
- Average Sales: Average sales value.
- Number of Items: Total items sold.
- Average Rating: Average customer rating.

 📈 Dashboard Features

- Interactive KPI cards.
- Sales analysis by item type.
- Outlet size and location analysis.
- Outlet establishment year analysis.
- Fat content-based sales analysis.
- Customer rating analysis.
- Dynamic slicers and filters for interactive exploration.

 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

 🔍 Data Analysis Process

1. Data Understanding: Explored the dataset and identified important business attributes.
2. Data Cleaning: Used Power Query to handle missing values and prepare the dataset.
3. Data Modeling: Organized the data for effective analysis.
4. DAX Calculations: Created measures for important KPIs.
5. Dashboard Development: Designed interactive charts, KPI cards, and filters.
6. Insights Generation: Analyzed sales performance across categories and outlets.

 💡 Key Learnings

- Practical experience with Power BI dashboard development.
- Data cleaning and transformation using Power Query.
- Creating calculated measures using DAX.
- Building interactive business intelligence reports.
- Converting raw data into meaningful business insights.
